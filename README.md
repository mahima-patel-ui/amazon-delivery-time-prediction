# 🚚 Amazon Delivery Time Prediction

## 📄 Overview
**Amazon Delivery Time Prediction** is a machine learning project that predicts delivery durations based on various real-world factors such as distance, weather, traffic, and shipment type.  
This project aims to help logistics companies improve delivery accuracy, reduce delays, and optimize route planning.

---

## ⚙️ Tech Stack
- **Python**
- **Pandas, NumPy**
- **Scikit-learn**
- **Matplotlib, Seaborn**
- **XGBoost**
- **Jupyter Notebook**

---

## 🎯 Objectives
- Analyze key factors that affect delivery time  
- Build and evaluate ML models to predict delivery duration  
- Optimize logistics decisions based on data insights  
- Visualize relationships between parameters such as distance, delivery person rating, and traffic density  

---

## 📊 Dataset
The dataset includes detailed order and logistics records with the following columns:
- Delivery Person ID  
- Delivery Location & Distance  
- Weather Condition  
- Traffic Density  
- Vehicle Type  
- Delivery Person Ratings  
- Actual Delivery Time (Target Variable)

---

## 🧠 Project Workflow
1. Data Cleaning and Handling Missing Values  
2. Feature Engineering (distance, traffic, weather encoding)  
3. Exploratory Data Analysis (EDA)  
4. Model Training (Random Forest, XGBoost)  
5. Model Evaluation using MAE, RMSE, and R² Score  
6. Generating Final Predictions for new delivery data  

---

## 📈 Results
- Achieved **R² Score of 0.92** and **MAE of 5.6 mins** on validation data  
- Identified top 3 delay factors: *traffic density, distance, and weather conditions*  
- Improved delivery time prediction accuracy by **15%**
